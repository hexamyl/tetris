# Tetris

This is a simple web-based Tetris game.

## Running the game

To run the game, you can use a simple Python server.

1.  Make sure you have Python installed.
2.  Open a terminal in the `webgame` directory.
3.  Run the following command:

    ```bash
    python -m http.server
    ```

4.  Open your web browser and go to `http://localhost:8000`.

Enjoy the game!
